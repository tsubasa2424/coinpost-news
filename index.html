📖 LINEの設定方法
1
LINE Developersでチャネルを作成
developers.line.biz にアクセス → 新規プロバイダー → 新規チャネル → Messaging API を選択
2
チャネルアクセストークンを発行
チャネル設定 → Messaging API → 「チャネルアクセストークン（長期）」を発行してコピー
3
自分のUser IDを確認
LINE Developersコンソール上部の「Your user ID」に表示（Uから始まる文字列）
4
公式アカウントを友だち追加
作ったLINE公式アカウントを自分で友だち追加する（これをしないとPush通知が届きません）
5
環境変数を設定してサーバーを起動
export LINE_CHANNEL_ACCESS_TOKEN="取得したトークン"
export LINE_USER_ID="UxxxxxxxxxxxxxxxxxxxxX"
python app.py
